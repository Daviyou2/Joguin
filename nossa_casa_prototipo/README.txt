# Nossa Casa — Protótipo

Protótipo inicial em HTML/CSS/JavaScript.

## Como abrir
1. Extraia o ZIP.
2. Abra `index.html` no navegador.
3. Compre móveis.
4. Arraste os móveis para dentro da casa.
5. Os móveis geram moedas por segundo.
6. Depois de alguns móveis, a próxima casa é liberada.
7. Na Casa 3 aparecem Lucas, Arthur e Aurora.
